# IsaacFPS

Roguelike-игра от первого лица по мотивам The Binding of Isaac.
Учебный проект по проектному практикуму, 2 курс.

## Управление

| Клавиша | Действие |
|---------|----------|
| WASD | Движение |
| Мышь | Обзор |
| ЛКМ | Стрельба |
| Space | Прыжок |
| Escape | Освободить курсор |

## Как запустить

### Требования
- [Godot 4.4](https://godotengine.org/download) (Standard version)

### Запуск
1. Скачай репозиторий: кнопка **Code** → **Download ZIP** или через git: https://github.com/shins3n/IsaacFPS.git
2. Открой Godot → **Import** → выбери файл `project.godot`
3. Нажми **F5** для запуска
